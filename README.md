# Fumacraft

Loja online com pedidos pelo WhatsApp, pronta em 5 minutos, para pequenos vendedores (Brasil, Portugal, Angola, Moçambique e mais).

- `index.html` — app completo (landing, painel do vendedor, loja, checkout via WhatsApp)
- Plano: US$9,99/mês com 7 dias grátis (checkout Lemon Squeezy — definir `CHECKOUT_URL`)
- PWA instalável (manifest + service worker)

Próximas fases: backend (contas, lojas guardadas na nuvem, links curtos), cobrança automática da assinatura, versão em inglês.
